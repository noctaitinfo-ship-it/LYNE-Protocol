# LP 0.1 examples

Generated by `python 03_Protokoll/tests/gen_examples.py --write`. Do not edit by hand:
`tests/run_tests.py` fails if a file differs from the generator output.

All keys, secrets, identifiers and signatures here are TEST VECTORS derived from public labels
(prefix `LYNE LP 0.1 TEST VECTOR - NOT A SECRET - `). They MUST NOT be used outside tests.

- `valid/` — one consistent lifecycle with real Ed25519 signatures (detached JWS over JCS):
  Thing → State 1 (WAITING on client) → Grant → Redemption statement and provider Receipt →
  Result (both signatures) → State 2 anchored to the Result. `vectors.json` holds derivation
  vectors: secret commitment, delivery link, rendezvous addresses, hashes of `K_signal_p2c` and
  `K_signal_c2p`. `signal.json` holds a signed signal message per direction (a `p2c` offer, a `c2p`
  answer) and its AES-256-GCM envelope with a deterministic test nonce.
- `invalid/` — each file violates exactly one schema rule; the file name names the rule.
- `tampered/` — schema-valid, but altered after signing; signature verification MUST fail.
- `semantic-invalid/` — schema-valid and correctly signed, but violating a rule that JSON Schema
  cannot express (for example a bearer window longer than 15 minutes); the time-rule check MUST
  reject it.
